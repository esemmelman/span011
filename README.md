# Ser and estar together

A small Spanish practice app patterned after `span010`. The reference page shows ten mixed examples of **ser** and **estar**, including identity, origin, characteristics, locations, feelings, and conditions. Exercise 1 asks for the correct conjugated verb. Exercise 2 asks learners to build each Spanish sentence from three word columns. Both exercises score answers and offer a fresh set.

Open `index.html` in a browser. No build step or dependencies are required. The GitHub Pages workflow publishes changes pushed to `main`.
