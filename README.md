# Ser and estar together

A beginning-level Spanish practice app patterned after `span010`. The reference page shows ten mixed examples of **ser** and **estar**, including identity, origin, characteristics, locations, feelings, and conditions. Exercise 1 offers the two verb forms for the subject. Exercise 2 asks learners to build each Spanish sentence from three word columns with at most five choices each. Both exercises score answers and offer a fresh set.

Open `index.html` in a browser. No build step or dependencies are required. The GitHub Pages workflow publishes changes pushed to `main`.
